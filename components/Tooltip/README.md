# Tooltip

A `small` label in a `popover`-grounded box with `border`, `radius-sm`, `shadow-sm`, 4px by 8px padding, max 240px, shown after 400ms hover or immediately on keyboard focus, placed above by default. Tooltips name icon-only buttons (mandatory), show absolute timestamps behind relative ones, and give full values behind truncated cells. They never hold actions, links or anything the operator must read to proceed; that content goes inline. The consumer provides the text; the system fixes timing and placement.
