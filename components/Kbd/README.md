# Kbd

Keyboard shortcut caps, shown next to menu items, in tooltips, in the CommandPalette and on a shortcuts sheet (opened with `?`). A cap is `mono` 11px in `muted-foreground` on a `secondary` ground with a `border` and `radius-sm`, 20px tall, min 20px wide; combinations join caps with a 4px gap, no plus sign; sequences (G then A) are two caps separated by "then" in `small`. Use the platform symbol (⌘ on macOS, Ctrl elsewhere) and never bind single letters that type into a focused field. The consumer provides the keys; the system fixes the rendering and reserves `?`, `/`, `⌘K` and `Esc`.
